
# ME Technologies Website

## About the Project
A responsive solar energy website developed for ME Technologies as part of the Code Saviours Web Development Internship.

The website presents solar design services and energy solutions for homes, businesses, industries, and agriculture.

## Website Pages
- Home
- About
- Services
- Projects
- Contact

## Features
- Responsive website layout
- Navigation between pages
- Solar service and project cards
- Project category filters
- Image lightbox
- Contact form validation
- Formspree contact form integration
- Embedded map

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Formspree
